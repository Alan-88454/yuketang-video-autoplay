# 雨课堂（长江雨课堂）视频自动连播助手

一个本地加载的 Edge 扩展。装上之后，它会在雨课堂课程页上：

1. 自动找到**未完成**的视频小节并点开
2. 接管播放器：按设定倍速播放、静音、防止误暂停
3. 一节播完**自动切换到下一节**
4. 跳过图文、讨论、作业、测验、考试，以及未开放（带锁）的小节
5. 直到本课程所有视频播完，弹出提示并停止

已适配雨课堂两套主要页面结构：

- 旧版课程页：`/pro/lms/{课程}/{班级}/studycontent`（视频在新标签页打开）
- 新版学习空间：`/ai-workspace/lms-graph/{班级}`（左侧目录 `.leaf-item` 与播放器在同一页，
  每一章各自一个 `.nav-item-list`）

新版学习空间的章节树在**视频页上也有**，所以播完点下一节是同一页内的切换，不需要来回跳转。

新版学习空间里"看没看过"是用图标画的，没有文字。脚本按真实标记判断：

| 第 2 列图标 | 含义 | 脚本行为 |
| --- | --- | --- |
| 实心圆对勾 | 已完成 | 跳过 |
| 圆形进度环 | 看过一部分 | 接着播（雨课堂会从上次位置续播） |
| 空的 | 未开始 | 从头播 |
| 标签写"讨论 / 图文 / 作业" | 非视频 | 跳过 |

如果两套已知结构都没命中，脚本会**自动识别**："页面上哪个容器装着一批结构相同的小节"——
再结合小节里的类型标签（视频/图文/作业…）、图标类名和"已完成"状态来分类，不依赖写死的类名。

## 它不会做的事

- 不拖动进度条、不跳段、不改播放位置
- 不伪造进度上报（进度仍由播放器自己按正常节奏上报给雨课堂）
- 不自动答题：遇到必须作答的弹窗会**暂停并提示**，由你手动处理
- 不自动登录、不读取或保存你的账号密码
- 不发任何外部网络请求，只申请 `*.yuketang.cn` 的权限

## 安装

1. 打开 Edge，地址栏输入 `edge://extensions/`
2. 打开左下角（或左侧栏）的「**开发人员模式**」
3. 点「**加载解压缩的扩展**」，选择解压出来的那个文件夹（里面能直接看到 `manifest.json` 和 `src` 文件夹）
4. 列表里出现「雨课堂视频自动连播助手」即安装成功

升级代码后：回到 `edge://extensions/`，在这个扩展上点「重新加载」即可。

**改了代码必须重新加载才生效。** 面板标题栏和自检报告里的 `version` 会显示当前运行的版本号，
对不上就说明还没重载。当前版本：`1.0.7`。

注意顺序：**先在 `edge://extensions/` 重新加载扩展，再刷新雨课堂页面。**
只重载扩展而不刷新页面，页面里跑的还是旧脚本。

## 使用

1. 正常登录雨课堂，进入你的课程，打开「**学习内容**」页（左侧能看到章节列表那一页）
2. 页面右侧会出现一个蓝色悬浮面板
3. **第一次使用**建议先点「**环境自检**」，确认列表里 `chapterItems.selector` 不是 `null`、
   `detectRole` 是 `driver`，说明页面结构已被正确识别
4. 点「**开始**」，面板会在 3 秒后收起成右下角的小圆球，可以点它展开
5. 之后可以去做别的事，全部播完会弹出提示

### 面板上的设置

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| 播放倍速 | 2.0x | 可切回 1.0x 原速；见下方说明 |
| 自动静音 | 开 | 避免多个视频连续播放互相打扰 |
| 反切屏保持播放 | 开 | 切到其他软件时视频不中断（见下方说明） |
| 刷新后自动续跑 | 开 | 课程页刷新或页内跳转后自动接着播 |
| 播完关闭视频页 | 开 | 新标签页播放模式下，播完自动关掉该标签页回到课程页 |
| 清除本课程播放记录 | — | 需要重看时用，点一下就会重新扫描全部视频 |

### 关于倍速

面板默认 2.0x。**注意**：如果你们课程的规则里"不允许快进"包含加速播放，请把倍速切回
`1.0x 原速`——面板顶部随时可改，改完对下一个视频立即生效。

雨课堂的播放器**不认**直接设置 `video.playbackRate`：它以自己的倍速状态为准，会把你设的值拉回去
——实测它每 0.3 秒左右就把自己的状态刷回 video 元素一次，所以直接设值必然被覆盖
（表现就是面板显示 2x、播放器右下角仍写着 1.00X）。静音同理。

**它的倍速菜单也点不动**：那个菜单靠 CSS `:hover` 展开，而合成事件无法让浏览器进入
`:hover` 状态——所以从内容脚本里点菜单项是死路（能跑通的方案都用了操作系统级的真实鼠标输入）。

所以脚本改用**媒体状态锁**：在页面自己的 JS 世界里把 `<video>` 的 `playbackRate` /
`muted` / `volume` 三个属性的 setter 包一层，锁开启时**吞掉播放器的回写**，只放行脚本自己的写入。
播放器想把倍速改回 1x 也改不动。

界面上那个倍速标签：脚本会把播放器倍速菜单里**高亮的那一项**挪到与真实倍速相符的选项上
（只挪高亮，不改选项文字，否则会把菜单改坏）。如果播放器的标签是取"当前选中项"的文字，
它就会跟着显示 `2.00X`；如果它维护的是一个独立标签，那它仍会显示 `1.00X`。

**判断有没有生效，看面板「倍速」那一行**——它读的是 video 元素的真实值
（`video.playbackRate`），不是播放器界面上的文字。也可以直接看视频进度是不是走得明显更快。

锁只在会话运行期间生效；点「停止」就会解锁，播放器恢复自主控制。
锁开启时你从播放器界面手动改倍速/音量不会生效——请用面板改。

切视频时播放器常会新建 `<video>` 元素，新元素默认没上锁。脚本用 `MutationObserver`
在节点出现的当下立刻补锁，另加 150ms 定时兜底，避免出现"刚切换那几秒掉回 1 倍速"。

第二条生效时日志里会出现 `直接设置 2x 没生效，改用播放器自带的倍速菜单`，
播放器右下角的倍速指示也会跟着变成 2.00X。面板上的"倍速"显示的是**实际生效值**，
不是你的设置值——以它为准。两条路都不通时会回落原速并告诉你。

### 关于「反切屏保持播放」

雨课堂会在标签页失去焦点时自动暂停视频。这个开关会拦截页面的可见性/失焦监听，
让视频在后台继续播放，这样你才能切去做别的事。它不改变播放进度，也不影响任何进度上报。
如果你不希望修改页面行为，可以在面板里关掉它，代价是必须让雨课堂页面保持在前台。

### 关于「静音方式」

浏览器（Chromium 内核，Edge/Chrome 都是）有个省电机制：**当页面处于后台、而视频又"听不到声音"
时，会把视频暂停掉**。脚本如果去抢回播放，浏览器又暂停，就变成每秒几百次的拉锯，
视频只有不到一半的实际速度，日志里会出现：

```
AbortError: The play() request was interrupted because
video-only background media was paused to save power.
```

所以面板里给了三档：

| 档位 | 行为 | 什么时候用 |
| --- | --- | --- |
| **自动**（默认） | 先真静音；一旦发现上面的省电暂停，自动改成「极低音量」并把标签页静音 | 一般就用这个 |
| 真静音 | 始终 `muted = true` | 你就想让页面完全无声，且能接受最小化时可能被拖慢 |
| 极低音量 | 始终 `muted = false` + 音量 `0.001`，并把标签页静音 | 想强制走"浏览器认为它在出声"这条路 |

「极低音量」的原理是让浏览器认为视频在发声，从而不走省电路径；音量 0.001（约 -60dB）人耳听不到，
而且脚本会额外把整个标签页静音，听感上就是完全安静的。

如果自动切换之后 `playErrors` 里**仍然**在出现 `paused to save power`，那就是浏览器层面
还在暂停它，请到 Edge「**设置 → 系统和性能**」里关闭「**效率模式**」和「**睡眠标签页**」，
或者把 `changjiang.yuketang.cn` 加进例外列表。

## 出问题了怎么办

- **面板没出现**：确认你在 `*.yuketang.cn` 的学习相关页面（`/pro/lms/`、`/studycontent`、
  `/student-log` 等）；`edge://extensions/` 里确认扩展已启用。
- **提示"未找到章节列表"**：说明自动识别也没找到。点「**环境自检**」→「复制报告」，
  把 JSON 发回给我，我会按 `structure` 里的实际结构补适配。
- **提示"未发现可用播放器"**：点开自检报告，看 `videoState` 和 `frames[].videos`。
- 自检报告里和结构有关的字段：
  - `structure.autoDetectedTree`：自动识别到的章节树（数量、得分）——不是 `null` 就说明识别成功
  - `structure.listContainers`：页面上所有"有 3 个以上同构子元素"的容器，章节树通常在其中
  - `structure.chapterLikeClasses`：按 class/id 关键词归类，用来确认真实类名
  - `structure.playerControls`：播放器上的「下一集 / 倍速」等控件
- **某几节一直播不动**：面板会暂停并提示，处理完点「继续」。连续多节失败的项会被跳过，
  可以用「清除本课程播放记录」重来。
- **想临时停下**：点「暂停」；想彻底结束点「停止」。
- **窗口最小化后，切下一节时播放/暂停反复跳、视频卡住**：切下一节的过程中，雨课堂的播放器会
  反复把新视频按停，而脚本同时在把它抢回播放，两边对着抢就会表现为「播放/暂停来回跳」。
  `1.0.6` 起，会话运行期间脚本会**吞掉播放器自己发起的暂停**，只在三种情况下放行：
  你刚刚亲手操作过（1.5 秒内）、视频已经播到片尾、或者那不是当前正在接管的那个视频元素。
  所以你手动点播放器的暂停按钮仍然有效。

  `1.0.7` 起，还从根上处理了最小化时更常见的一种情况：**浏览器为省电暂停后台"没声音"的视频**。
  脚本发现后会改成「极低音量 + 标签页静音」，让浏览器不再暂停它（详见上面「关于静音方式」）。
  同时给重播加了节流，不会再每秒抢几百次把 CPU 烧掉。

  这条修复的证据链在自检报告里：`pauseDiag.blocked` 是"页面按暂停被抢回"的次数，
  `pauseDiag.stacks` 是被吞掉时的调用栈（能看出是播放器哪段代码在按暂停），
  `pauseDiag.holdPlay` 表示这个功能当前是否在生效，`playErrors` 里如果出现
  `NotAllowedError` 则说明是浏览器自动播放策略在拒绝 `play()`。
  如果最小化时仍然卡，请点「环境自检」把报告发我，看这四个字段就能定位。
- **视频播完后又被从头重播**：正常情况下脚本会拦住这种行为（播完的播放器不再自动 `play()`）。
  如果仍然出现，说明页面用了别的重播机制，请把自检报告发我。
- **明明没看却说已播完**：脚本只在"播放器区域"内判断完成状态（播放器时间显示 `当前/总时长`
  相等，或播放器内出现 100%）。侧边目录和右下角状态条里到处都写着"已完成"，脚本**不会**拿它们
  当成当前视频的完成依据。如果你遇到相反的情况，请把自检报告发我。
- **一开就提示"全部视频都显示为已完成"**：说明整门课在页面上都带了对勾图标。如果你确实还没看完，
  那多半是判定依据变了——请点「环境自检」把报告发我。脚本在这里选择**停下来问你**，而不是
  默认跳过整门课。
- **设了 2x 但一直按 1x 播**：看面板"倍速"那一行。如果它一直是 `1x`，而日志里
  `直接设置 2x 没生效，改用播放器自带的倍速菜单` 之后也没变化，等约 1 分钟会出现
  `点了播放器的倍速菜单但倍速仍是 1x`——这时请点「环境自检」把报告发我，
  报告里的 `structure.speedMenu` 会带上倍速菜单的真实结构（菜单选择器、每个选项的文字、
  选项内部的标签、倍速按钮的标签），照着改一次就准。

  先确认一件事：**面板"状态"那一行是不是"运行中"？** 如果是"未启动"或"已暂停"，
  说明扩展当前没有接管这个视频，静音和倍速当然都不会生效——点「开始」即可。
  自检报告里的 `session.running` 也是同一个意思。

  报告里还有 `controlProbe`，它会现场设一次静音和 2x 并读回：
  - `immediate` 和 `afterDirect` 一样 → 设置被接受了，那问题在扩展没运行
  - 两者不同 → 是被播放器拉回去了，这时看 `afterUiClick.activeSpeed`
    （`2.00X` 说明走播放器菜单这条路是通的）

## 文件结构

```
manifest.json          MV3 清单（权限：storage、tabs；域：*.yuketang.cn）
src/main-world.js      document_start 注入：绕过切屏暂停检测 + 锁住倍速/音量 + 会话期间保住播放
src/content.js         页面识别 / 章节分类 / 播放控制 / 完成判定 / 弹窗处理 / 面板 / 自检
src/background.js      Service Worker：课程页与视频页的信号转发、标签页收尾、标签页级静音
build.ps1              把上面这些文件打成一个可分发的 zip
README.md              本文件
```

打包分发包：

```powershell
pwsh -File .\build.ps1
```

会生成 `dist/yuketang-video-autoplay-v<版本号>.zip`。对方解压后，把里面那层文件夹
用「加载解压缩的扩展」装进 Edge 即可。

## 已知限制

- 已知类名覆盖 `/pro/lms/` 与 `/ai-workspace/lms-graph/`；未来若再改版，自动识别仍应可用，
  若失效请按自检报告补适配。
- 播放记录按「课程路径 + 小节序号 + 小节标题」保存。若课程章节顺序或标题变化，
  记录可能对不上，此时用「清除本课程播放记录」重来即可。
- 一次只处理当前打开的那一门课程。
